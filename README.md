# DVF Insights

Plateforme d'analyse du marché immobilier français fondée sur les données ouvertes DVF (Demandes de Valeurs Foncières, data.gouv.fr).

Stack : React 18 · Vite · TypeScript strict · Tailwind CSS · Recharts · Supabase · n8n · Vercel.

Documentation technique complète à venir (architecture, stratégie data, liens de production).
